# Теория

## Быстрая сортировка (Quick Sort)

Быстрая сортировка состоит из следующих этапов:
1. Определение базового случая(массив из нуля или из одного элемента не надо сортировать)
2. Определение опорного элемента(pivet) (им может выступать любой элемент массива)
3. Далее массив делится на три части: массив с меньшими значениями, чем опорный элемент(less) , самим pivet, массив с большими значениями, чем pivet (greater)
4. Для частей less и greater вызывается функция быстрой сортировки (рекурсия)

Самый простой выбор pivot по формуле arr[arr_length / 2] - то есть элемент по середине массива.

Алгоритм быстрой сортировки тесно связан со стратегией "разделяй и властвуй", которая основывается на том, что большую задачу следует на каждом шагу разбивать на более маленькую.

Быстрой сортировку называют так, потому в большинстве случаев она имеет время выполнения O(n log n). Однако в худшем случае время её выполнения будет O(n^2).

## Сортировка слиянием (Merge Sort)

### Преимущества

* Вид сортировки подходит для больших объёмов данных 
* Отлично работает со связными списками
* Гарантированно даёт время выполнения O(n log n)

### Недостатки

* На практике работает медленнее quick_sort , так как требует дополнительного выделения памяти

### Основы работы

В основе работы сортировки слиянияем лежит **разделение массива на две части** на каждому шагу, пока не получим отдельные части массива, каждая по одному элементу.
Каждый раз, когда происходит деление массива, необходимо выделять память на новые его части.
В заключительном этапе сортировки мы соединяем отдельные части массива, упорядочив их перед этим.
